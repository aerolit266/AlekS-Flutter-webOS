# Как участвовать

Откройте Issue с результатом проверки или Pull Request с изменением. Для совместимости укажите модель LG, версию webOS и прошивки, архитектуру и версию пакета.

1. Соберите демо по инструкции в README.
2. Укажите, прошли ли установка, запуск и появление первого кадра. Если интерфейс появился, проверьте стрелки и OK на физическом пульте.
3. Приложите короткий фрагмент ошибки или вывод теста. Удалите из него адреса устройств, имена пользователей, токены и ключи.
4. Если требуются другие версии зависимостей, укажите их в PR и добавьте SHA-256 скачанных архивов.

Для испытаний на webOS 5 сначала укажите точную модель и версию прошивки. Добавьте результат в таблицу совместимости после прогона на реальном телевизоре.
