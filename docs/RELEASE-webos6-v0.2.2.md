## webOS 6 · прототип 0.2.2

Исправлена обработка физических стрелок и OK на LG 65NANO896PC с webOS 6.6.0. SDL2/Wayland на этом телевизоре передаёт в поле клавиши необёрнутый scancode. Запускатель преобразует эти пять значений в обычные SDL keycodes, сохраняя обработку стандартной клавиатуры.

На реальном Magic Remote последовательность «вправо → вниз → OK» прошла до Flutter и подтвердила четвёртую карточку. Тест сопоставления охватывает все пять кнопок. Совместимость с webOS 5 ещё не проверена.

Этот предварительный релиз содержит исходники, скрипты сборки и документацию. Для локальной сборки IPK используйте README и зафиксированные версии зависимостей.
