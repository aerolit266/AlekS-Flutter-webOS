# webOS 6 · прототип 0.2.1

Первая публикация исходников нативного порта Flutter 3.38.10 для webOS 6. Включает запускатель на C, пример на Dart и сценарии сборки демо-IPK.

На LG 65NANO896PC с webOS 6.6.0 подтверждены установка, запуск, вывод первого кадра и программная навигация SDL. webOS 5 ждёт первого прогона на реальном телевизоре.

Версии и SHA-256 зависимостей указаны в `docs/DEPENDENCIES.md`, статус моделей — в `docs/COMPATIBILITY.md`. GitHub предоставляет архивы исходников для тега `webos6-v0.2.1`. Бинарный IPK в этот предварительный релиз не входит.
