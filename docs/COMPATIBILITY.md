# Совместимость

| Платформа | Модель | Что проверено |
|---|---|---|
| webOS 6.6.0 | LG 65NANO896PC, ARMv7 softfp | Установлен IPK 0.2.2. Владелец подтвердил работу физического Magic Remote при обычном запуске. В отдельном прогоне журнал Flutter подтвердил последовательность «вправо → вниз → OK» с выбором четвёртой карточки. |
| webOS 5.6.2 | ARMv7, семейство jimna | Ожидается первый запуск на реальном телевизоре. |
| Другие модели и версии webOS | Требуется проверка | Совместимость не установлена. |

В 0.2.1 синтетические события SDL проходили, но физический Magic Remote на проверенном LG не управлял приложением. В 0.2.2 запускатель распознаёт коды, которые отдаёт SDL2/Wayland на этом ТВ.
