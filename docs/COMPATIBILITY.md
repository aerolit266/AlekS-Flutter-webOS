# Совместимость

| Платформа | Модель | Что проверено |
|---|---|---|
| webOS 6.6.0 | LG 65NANO896PC, ARMv7 softfp | Установка демо-IPK 0.2.1, запуск через Application Manager, первый кадр SDL 640×360 и программная последовательность «вправо → вниз → OK» |
| webOS 5.x | Требуется проверка на конкретной модели | Ожидается первый отчёт об установке и запуске |
| Другие модели и версии webOS | Требуется проверка | Совместимость не установлена |

Результат программной подачи событий SDL относится к тестовому приложению. Для подтверждения физического пульта укажите, какие кнопки проверяли вручную.
